# Astralink 灵枢教务客户演示脚本

适用对象：朗睿教育管理层、教务主管、顾问、老师和财务试用评审。

演示建议先使用朗睿教育管理员账号：`admin@longrui.com / admin123`。

多机构隔离演示可切换：

- 我来教育：`admin@wolai.com / admin123`
- 广外留学：`admin@guangwai.com / admin123`
- AmazingX：`admin@amazingx.com / admin123`

这些账号仅用于本地 / staging 演示，生产环境必须修改密码。

## 1. 登录管理员账号

- 点击：打开 staging 地址，选择登录页「管理员」旁的「一键填入」，点击「登录」。
- 展示：系统自动进入首页看板，左侧显示完整功能菜单。
- 讲法：这是机构管理员视角，可以看到全机构教务、课时、报告和系统配置。

## 2. 查看首页看板

- 点击：首页看板。
- 展示：今日排课、待处理事项、低课时提醒、运营概览。
- 讲法：看板用于每天快速判断教务工作重点，减少人工翻表。

## 3. 查看学员管理

- 点击：侧边栏「学员管理」。
- 展示：演示学生、风险状态、负责顾问、学员详情。
- 讲法：学员档案是后续排课、消课、报告和 AI 查询的数据基础。

## 4. 新建排课

- 点击：侧边栏「排课日历」→「新建排课」。
- 展示：选择课程、老师、学员或班级、日期、时间、教室文本。
- 讲法：排课写入真实数据库，支持按周刷新和基础冲突检测。

## 5. 从排课生成上课记录

- 点击：日历中的课程块 → 右侧详情 →「生成上课记录」。
- 展示：上课记录与排课关联，保留课程、老师、学生、时间和教室信息。
- 讲法：系统把“排课计划”转为“可反馈和可消课的上课记录”。

## 6. 提交老师反馈

- 点击：侧边栏「上课记录」→ 打开记录详情 → 填写课堂内容、课堂表现、作业布置 →「提交反馈」。
- 展示：记录状态变为已提交，老师反馈进入家长报告和 AI 分析数据源。
- 讲法：老师只需要在课后补齐结构化反馈，后续报告和顾问跟进可以复用。

## 7. 确认消课

- 点击：上课记录详情中的「确认消课」区域 → 核对本次扣减课时 → 确认。
- 展示：消课成功、记录变为已消课，余额同步减少。
- 讲法：消课和课时流水自动联动，避免手工扣课时出错。

## 8. 查看课时流水

- 点击：侧边栏「订单课时」。
- 展示：课时账户、剩余课时、低课时预警和流水记录。
- 讲法：财务和教务可以追溯每一次购买、调整和消课扣减。

## 9. 创建请假补课申请

- 点击：排课详情或「请假补课」页面 → 新建学生请假 / 老师请假 / 调课申请。
- 展示：请假原因、原课程时间、是否需要补课。
- 讲法：把线下微信群里的请假补课流程结构化，方便审批和后续安排。

## 10. 安排补课

- 点击：请假补课申请详情 → 审批通过 → 安排新时间。
- 展示：生成新的补课排课，原记录状态同步变化。
- 讲法：补课不再靠人工备注，系统可追踪从申请到通知家长的完整状态。

## 11. 生成家长报告

- 点击：侧边栏「家长报告」→ 生成或打开报告 → 编辑并发送。
- 展示：报告读取真实上课记录、老师反馈、课时和请假补课数据。
- 讲法：家长报告减少顾问手工整理时间，同时避免暴露内部备注和财务敏感字段。

## 12. 使用 AI 教务助手查询低课时学生

- 点击：侧边栏「AI 教务助手」→ 快捷问题「查询低课时学生」。
- 展示：低课时学生卡片、课程、剩余课时、负责顾问和风险等级。
- 讲法：当前 AI 是规则型真实数据查询，先解决教务运营高频问题，后续可接真实大模型。

## 13. 生成续费建议

- 点击：AI 卡片中的「生成续费建议」或进入订单课时的 AI 续费建议区域。
- 展示：续费原因、顾问沟通要点和家长话术。
- 讲法：续费建议基于真实课时、反馈、请假补课和报告状态，适合顾问快速跟进。

## 14. 打开数据导入导出页面

- 点击：侧边栏「数据导入」。
- 展示：模板下载、上传预览、确认导入、批次列表和数据导出。
- 讲法：迁移历史学员、课程、老师、课时余额和排课记录时，可以先预览校验再写入。

## 15. 查看系统设置和权限

- 点击：侧边栏「系统设置」。
- 展示：机构信息、低课时阈值、通知/AI 开关、用户管理和权限矩阵。
- 讲法：试用阶段可以调整机构基础配置、管理演示账号，并确认不同角色的可见范围。

## 演示收尾

- 建议最后切换到老师、顾问、财务账号各演示 1 分钟。
- 重点展示不同角色看到的菜单和数据范围不同。
- 再切换到我来教育、广外留学、AmazingX 管理员账号，各打开一次「学员管理」和「AI 教务助手」低课时查询，说明所有数据都按机构隔离，不能跨机构查看。
- 收集客户反馈时优先问：排课流程、消课规则、家长报告内容、数据迁移字段是否符合真实业务。

# 朗睿教育试用演示脚本

## 演示目标

用 20-30 分钟展示 Astralink 灵枢教务系统如何支撑朗睿教育的第一阶段核心闭环：招生建档、课程排课、上课反馈、消课扣费、课时流水、家长报告和 AI 教务提醒。

## 演示前准备

1. 启动后端：

```bash
npm run backend:dev
```

2. 启动前端：

```bash
npm run dev
```

3. 打开 `http://localhost:3000`。

4. 准备管理员账号：

```text
admin@astralink.local / admin123
```

## 1. 登录系统

打开登录页，使用管理员账号登录。

讲解点：

- 当前是朗睿教育 staging 测试机构。
- 系统支持管理员、教务主管、顾问、老师、财务五类角色。
- 不同角色登录后菜单和操作按钮会自动变化。

## 2. 查看首页教务提醒

进入首页看板。

讲解点：

- 展示学员、班级、课时预警等关键指标。
- 作为教务主管每日工作台，用于发现待处理事项。

## 3. 新增学员

进入「学员管理」，点击「新增学员」。

建议录入：

```text
姓名：试用学生
手机号：13900000001
年级：10年级
学校：朗睿测试学校
购买课时：20
标签：AP / 续费关注
```

讲解点：

- 新增成功后学员列表自动刷新。
- 后端会同步创建课时账户。
- 如果接口失败，前端会提示错误，不会崩溃。

## 4. 新建排课

进入「排课日历」，点击「新建排课」。

建议选择：

```text
课程：AP微积分BC
老师：王建国
教室：Room 301
日期：本周任意日期
时间：10:00
时长：2 小时
```

讲解点：

- 新建成功后排课日历自动刷新。
- 后端会记录排课操作日志。
- 后续可扩展冲突检测、重复排课和消息通知。

## 5. 提交上课记录

进入「上课记录」，打开任意一条记录详情。

操作：

- 填写课堂反馈。
- 点击「一键生成家长反馈」。
- 点击「保存草稿」或准备进入消课环节。

讲解点：

- 老师角色重点使用该页面。
- AI 反馈当前为 mock 逻辑，后续可接真实大模型。

## 6. 确认消课

在上课记录详情中点击「提交并确认消课」。

讲解点：

- 系统会扣减学生剩余课时。
- 自动生成一条课时扣减流水。
- 操作会写入 `operation_logs` 便于审计。

## 7. 查看课时流水

进入「订单课时」。

讲解点：

- 展示购买、赠送、转入、消课、退款等课时变动。
- 财务角色可重点查看该页面。
- 右侧显示低课时学生，用于续费跟进。

## 8. 生成家长报告

进入「家长报告」。

操作：

- 点击「生成 AI 摘要」。
- 点击「发送给家长」。

讲解点：

- 报告基于上课记录、出勤、作业完成率等数据生成。
- 当前发送为模拟发送，后续可对接企业微信、短信或邮件。

## 9. 使用 AI 教务助手查询低课时学生

进入「AI 教务助手」，输入：

```text
哪些学生课时低于 5 小时？
```

讲解点：

- AI 助手会返回结构化结果。
- 当前支持低课时查询、老师未提交反馈查询、作业逾期查询和报告摘要。
- 后续可接入真实大模型，并加入权限范围限制。

## 10. 生成续费建议

进入「订单课时」，右侧「智能续费建议」点击「生成续费分析」。

讲解点：

- 根据剩余课时、学习进度和风险分析生成顾问跟进话术。
- 顾问可以直接用于续费沟通。

## 角色权限演示

### 教务主管

账号：

```text
manager@astralink.local / manager123
```

展示：

- 可访问学员、课程、班级、排课、上课记录、请假补课、老师中心、家长报告。
- 不显示财务概览、竞赛项目等管理员专属或财务专属页面。

### 老师

账号：

```text
teacher@astralink.local / teacher123
```

展示：

- 只显示课程产品、上课记录、作业测评等教学相关页面。
- 不显示订单课时、财务、老师中心等页面。

### 顾问

账号：

```text
advisor@astralink.local / advisor123
```

展示：

- 可查看学员管理、家长报告、订单课时续费提醒、AI 教务助手。

### 财务

账号：

```text
finance@astralink.local / finance123
```

展示：

- 只显示订单课时、财务概览和首页。
- 尝试新增学员会被后端权限拒绝。

## 演示收尾

建议向客户确认：

- 数据字段是否符合日常教务口径。
- 课时流水和消课流程是否符合财务要求。
- 老师反馈和家长报告是否符合朗睿当前服务流程。
- AI 提醒优先级是否符合实际工作习惯。

# Astralink 灵枢教务系统 V1 优先级路线图

## 优先级定义

| 优先级 | 定义 | 交付原则 |
|--------|------|----------|
| P0 | 正式上线必须完成 | 不完成则不上线 |
| P1 | 上线后第一轮迭代 | 不阻断上线，但影响效率 |
| P2 | 增强功能 | 提升竞争力或体验 |
| P3 | 暂不开发 | 超出 V1 目标或投入产出不匹配 |

## P0：正式上线必须完成

### 账号、权限与数据安全

| 功能 | 说明 | 验收标准 |
|------|------|----------|
| 正式登录与账号管理 | 支持管理员创建/停用账号，保留角色字段 | 五类角色可登录，禁用账号无法登录 |
| 角色菜单与后端权限一致 | 前端隐藏菜单，后端接口也必须拦截 | 直接请求越权 API 返回 403 |
| 数据范围控制 | 顾问看负责学员，老师看自己课程和记录，财务看财务数据 | 关键列表按角色过滤 |
| 操作日志 | 覆盖新增学员、排课、消课、课时调整、报告发送 | 日志可查询到操作者、时间、对象和结果 |
| 敏感字段脱敏 | 家长电话、财务金额、导出数据按角色控制 | 非授权角色无法查看或导出敏感数据 |

### 学员与课程主数据

| 功能 | 说明 | 验收标准 |
|------|------|----------|
| 学员 CRUD | 新增、查看、编辑、软删除/归档 | 学员档案可完整维护 |
| 学员字段确认 | 入学信息、家长电话、顾问、标签、目标方向 | 与客户字段确认表一致 |
| 课程产品 CRUD | 新增、查看、编辑、上下架 | 课程可用于班级和排课 |
| 教师档案维护 | 老师信息、科目、类型、可用时间 | 排课可选择有效老师 |
| 班级管理 | 班级创建、学员加入、容量控制 | 超员有提示或拦截 |

### 教务核心流程

| 功能 | 说明 | 验收标准 |
|------|------|----------|
| 排课创建与列表 | 按老师、课程、教室、日期创建排课 | 创建后日历刷新 |
| 基础冲突检测 | 老师、教室、同一班级时间冲突 | 冲突时提示并阻止保存或需管理员确认 |
| 排课取消/改期记录 | 保留取消原因和操作日志 | 取消后状态正确 |
| 上课记录生成 | 可由排课生成记录，也可手动补录 | 记录关联学员、老师、班级 |
| 老师反馈提交 | 支持课堂表现、作业、AI 摘要、是否同步家长 | 提交后状态变为已提交 |
| 确认消课 | 基于上课记录扣减课时 | 余额扣减且生成流水 |
| 课时流水查询 | 查询购买、赠送、消课、退款、手动调整 | 余额与流水一致 |

### 请假补课与家长报告

| 功能 | 说明 | 验收标准 |
|------|------|----------|
| 请假补课基础流程 | 创建申请、审批、安排补课、标记完成 | 状态流转清晰 |
| 是否扣课时规则 | 按客户规则决定是否消耗或返还课时 | 规则在流水中可追溯 |
| 家长报告生成 | 从上课记录、出勤、作业和成绩生成报告 | 报告内容可预览 |
| 家长报告发送状态 | 模拟发送或记录实际发送结果 | 状态可从 generated 变为 sent |
| 家长可见字段控制 | 家长报告不泄露内部备注和财务敏感数据 | 字段与确认表一致 |

### 数据迁移与上线

| 功能 | 说明 | 验收标准 |
|------|------|----------|
| 学生 Excel 导入 | 支持模板、预览、错误提示 | 错误行不写入 |
| 课程、老师导入 | 支持基础主数据导入 | 重复数据可识别 |
| 课时余额导入 | 支持按学员导入期初余额 | 导入后生成期初流水 |
| 历史排课/上课记录导入 | 支持指定时间范围历史数据 | 关联关系校验通过 |
| 订单数据导入 | 支持历史订单和付款状态 | 财务核对一致 |
| 回滚方案 | 按导入批次回滚 | 回滚后数据一致 |

## P1：上线后第一轮迭代

| 功能 | 说明 | 价值 |
|------|------|------|
| 批量/周期排课 | 按周、老师、班级批量创建排课 | 降低教务排课工作量 |
| 课时调整审批 | 财务调整需管理员或主管审批 | 降低误操作风险 |
| 老师待办提醒 | 待提交反馈、今日课程、作业待批改 | 提升老师及时性 |
| 顾问续费工作台 | 低课时、快到期、未跟进学生集中展示 | 提升续费效率 |
| 报告导出 PDF | 将家长报告导出为 PDF | 支持线下发送 |
| AI 续费建议 | 根据课时、出勤、学习表现生成建议 | 辅助顾问沟通 |
| 数据导出中心 | 按角色导出学员、课时、课程等数据 | 方便运营核对 |
| 通知发送记录 | 记录短信、企业微信、邮件发送历史 | 支持服务留痕 |

## P2：增强功能

| 功能 | 说明 | 价值 |
|------|------|------|
| 作业独立模块 | 作业发布、提交、批改、附件 | 完整教学闭环 |
| 测评与成绩曲线 | 阶段测评、分数趋势、错题标签 | 提升教学分析 |
| 竞赛项目管理 | 竞赛报名、节点、成果、证书 | 支撑竞赛业务 |
| 家长端门户 | 家长查看课表、报告、作业和通知 | 提升服务透明度 |
| 老师端移动适配 | 老师手机端快速提交反馈 | 提升使用率 |
| AI 报告深度生成 | 基于多节课自动生成长周期报告 | 降低顾问写作负担 |
| BI 经营看板 | 课消、续费、老师效率、课程毛利 | 辅助管理决策 |
| 文件云存储 | 对接对象存储、权限链接和病毒扫描 | 支撑正式附件规模 |

## P3：暂不开发

| 功能 | 暂缓原因 | 重新评估条件 |
|------|----------|--------------|
| 完整 CRM 销售漏斗 | 超出教务 V1 范围 | 客户确认销售管理为核心需求 |
| 在线支付 | 涉及支付合规、退款、对账 | 订单流程稳定后再做 |
| 多机构集团管理 | 当前仅服务朗睿单机构试用 | 出现集团多校区客户 |
| 复杂薪酬结算 | 老师薪酬规则未确认 | 老师课消与结算口径稳定 |
| 原生移动 App | 成本高，V1 可用 Web 适配 | 移动端日活明确 |
| 真实大模型私有部署 | 成本与安全评估复杂 | AI 使用频率和 ROI 明确 |
| 自动排课算法 | 规则复杂且需大量约束输入 | 手动排课流程稳定后 |

## 里程碑建议

| 阶段 | 时间建议 | 目标 |
|------|----------|------|
| V1 范围冻结 | 第 1 周 | 完成字段、权限、导入模板确认 |
| P0 开发与联调 | 第 2-4 周 | 完成核心闭环和数据迁移工具 |
| UAT 验收 | 第 5 周 | 使用客户样本数据跑完整流程 |
| 正式上线 | 第 6 周 | 完成培训、导入、切换和首周支持 |
| P1 迭代 | 上线后 2-4 周 | 根据真实使用反馈优化效率功能 |

## 3. 每个角色能看到什么

### 管理员

- 可看：首页、学员、课程、班级、排课、上课记录、请假补课、家长报告、订单课时、数据导入导出、AI 教务助手、系统设置、用户管理。
- 适合验证：完整业务流程、机构设置、用户管理、权限矩阵、多机构隔离。

### 教务主管

- 可看：教务相关数据，包括学员、课程、班级、排课、上课记录、请假补课、家长报告、AI 教务助手。
- 适合验证：排课、反馈、请假补课、报告和日常教务待办。

### 顾问

- 可看：自己负责学生相关数据、家长报告、课时状态、AI 跟进建议。
- 适合验证：学生跟进、低课时提醒、家长沟通话术、报告内容。

### 老师

- 可看：本人排课、本人上课记录、老师反馈。
- 适合验证：课后填写反馈、提交反馈、查看自己的课程安排。

### 财务

- 可看：订单课时、课时账户、课时流水和授权导出。
- 适合验证：消课后余额变化、课时流水追溯、低课时状态。

## 4. 推荐试用流程

1. 登录管理员账号，查看首页看板。
2. 进入学员管理，打开学员详情，检查字段是否够用。
3. 进入课程产品，查看课程分类、课时和状态。
4. 进入班级管理，查看班级学生、课程和老师绑定。
5. 进入排课日历，新建一条排课或打开已有排课。
6. 从排课生成上课记录。
7. 填写老师反馈并提交。
8. 在上课记录中确认消课。
9. 进入订单课时，查看余额和课时流水。
10. 创建或查看请假补课申请，检查审批和安排补课流程。
11. 生成或打开家长报告，检查是否适合发给家长。
12. 进入 AI 教务助手，测试低课时、未提交反馈、待处理补课和高风险学生查询。
13. 进入数据导入导出，下载模板、预览导入、查看导出。
14. 进入系统设置，查看机构信息、低课时阈值、用户管理和权限矩阵。
15. 切换我来教育、广外留学、AmazingX 管理员账号，验证多机构隔离。

## 5. 不建议客户随意操作的地方

- 不建议大量删除或停用演示账号，以免影响其他试用人员。
- 不建议反复执行大批量导入；如需测试导入，建议用一两行测试数据，并在测试后回滚批次。
- 不建议把真实学生隐私数据上传到 staging；staging 仅用于功能验证。
- 不建议修改所有测试账号密码；如需验证重置密码，请新建一个测试账号后操作。
- 不建议把 staging 生成的家长报告直接发送给真实家长。
- 不建议在不了解规则时调整低课时阈值、课时透支等配置；可先记录需求，由项目组统一确认。

## 7. 常见问题

| 问题 | 说明 |
|------|------|
| 首次打开很慢 | Render 免费实例可能休眠，首次访问后端会有冷启动。 |
| 登录失败 | 请确认账号密码是否来自本说明，或联系管理员确认账号是否停用。 |
| 页面没有某个菜单 | 不同角色权限不同；可切换管理员账号查看完整功能。 |
| 页面刷新后打不开子路由 | 请反馈具体 URL，通常需要检查 Vercel rewrite 配置。 |
| AI 回答不像真实大模型 | 当前为规则型 AI / Mock AI，已读取真实数据库，后续可接真实 AI API。 |
| 导入预览失败 | 请使用系统下载的模板，并至少填写一行有效数据。 |
| 数据与上次试用不同 | staging 演示环境可能发生测试导入、回滚或重新部署，数据以当前页面为准。 |
| 多机构数据看起来一样 | 请退出登录、刷新页面后重新登录不同机构账号；仍异常请截图反馈。 |

## 8. 反馈方式

建议客户按模块反馈：

- 学员管理：字段是否够用，是否缺少重要标签或跟进字段。
- 排课日历：是否符合真实排课习惯，是否需要更多筛选。
- 上课记录：老师反馈字段是否够用。
- 消课课时：扣减规则、流水字段、低课时提醒是否清楚。
- 请假补课：审批和安排补课是否符合机构实际流程。
- 家长报告：内容是否适合直接发给家长。
- AI 助手：哪些查询最有用，哪些结论需要更谨慎。
- 数据导入导出：模板字段是否覆盖历史数据迁移。
- 权限设置：管理员、教务、顾问、老师、财务权限是否合理。

可使用：`docs/client-feedback-form.md`。

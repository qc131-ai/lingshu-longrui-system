# Astralink 灵枢教务系统 V1 试用反馈汇总

## 文档目的

本文档用于整理朗睿教育客户试用反馈，将问题、需求和上线决策按业务模块归类，作为 V1 正式版范围确认依据。

## 反馈分级

| 等级 | 含义 | 处理方式 |
|------|------|----------|
| 阻断 | 影响正式上线或核心流程无法完成 | 纳入 P0 |
| 重要 | 影响主要用户效率或数据准确性 | 优先纳入 P0/P1 |
| 一般 | 体验优化或低频需求 | 纳入 P1/P2 |
| 暂缓 | 当前不符合 V1 目标或投入过高 | 纳入 P3 |

5. 正式上线验收人、验收流程和上线日期。

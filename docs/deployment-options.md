# Astralink 灵枢教务系统部署方案

## 方案概览

V1 正式版建议提供两种部署方式：

1. Astralink 云端托管版：由 Astralink 统一托管、运维和升级。
2. 客户专属实例 / 私有化部署：为单个客户独立部署，数据和资源隔离更强。

## 方案一：Astralink 云端托管版

### 技术架构

| 层级 | 方案 |
|------|------|
| 前端 | 静态资源托管到 CDN 或对象存储 |
| 后端 | Node.js + Express 服务，容器化部署 |
| API 网关 | 统一 HTTPS 入口，按域名或路径路由 |
| 数据隔离 | 同一套服务，多租户 `organization_id` 隔离 |
| 鉴权 | 统一登录服务，角色权限控制 |
| 日志 | 集中日志采集和错误监控 |

### 数据库

| 项目 | 说明 |
|------|------|
| 类型 | PostgreSQL 15+ |
| 部署方式 | 云数据库托管服务 |
| 隔离方式 | 逻辑隔离，核心表使用 `organization_id` |
| 连接方式 | 后端服务通过内网连接数据库 |
| 扩展方式 | 根据客户数量扩容实例或拆分数据库 |

### 文件存储

| 项目 | 说明 |
|------|------|
| 存储介质 | 对象存储 |
| 文件类型 | 学员材料、作业附件、合同、报告文件 |
| 访问控制 | 后端签名 URL 或鉴权代理 |
| 生命周期 | 可按客户或文件类型配置保留周期 |

### 备份策略

| 类型 | 策略 |
|------|------|
| 数据库自动备份 | 每日自动备份，保留 7-30 天 |
| 数据库手动备份 | 重大版本发布前手动快照 |
| 文件备份 | 对象存储跨区域或版本控制 |
| 恢复演练 | 每季度至少一次恢复演练 |
| 导出备份 | 支持按机构导出核心业务数据 |

### 适合客户

- 希望快速上线的中小型教育机构。
- 没有专门 IT 运维团队的客户。
- 可以接受云端托管和多租户逻辑隔离的客户。
- 对持续升级和快速迭代有较高需求的客户。

### 优点

| 优点 | 说明 |
|------|------|
| 上线快 | 不需要客户准备复杂基础设施 |
| 运维成本低 | Astralink 统一负责部署、监控、备份和升级 |
| 升级方便 | 新功能可快速发布给所有客户 |
| 成本可控 | 多客户共享基础设施 |
| 支持弹性扩展 | 可根据客户数量和数据量扩容 |

### 缺点

| 缺点 | 说明 |
|------|------|
| 数据隔离弱于独立实例 | 依赖租户字段和权限隔离 |
| 客户定制受限 | 不适合大量私有流程和深度定制 |
| 合规要求需评估 | 高敏客户可能要求独立环境 |
| 升级窗口需协调 | 统一升级可能影响多个客户 |

### 预估维护成本

| 成本项 | 预估 |
|--------|------|
| 基础云资源 | 低-中 |
| 数据库 | 中，随客户数量增长 |
| 对象存储 | 低，随附件量增长 |
| 运维人力 | 低，统一运维 |
| 客户支持 | 中，按客户数增加 |
| 适合收费模式 | SaaS 年费 / 月费 |

## 方案二：客户专属实例 / 私有化部署

### 技术架构

| 层级 | 客户专属实例 | 私有化部署 |
|------|--------------|------------|
| 前端 | 独立域名和静态资源 | 部署在客户指定环境 |
| 后端 | 独立容器或虚拟机 | 部署在客户内网或私有云 |
| API 网关 | 独立 HTTPS 入口 | 客户网关或内网入口 |
| 数据隔离 | 独立数据库或独立 schema | 客户完全独立数据库 |
| 鉴权 | 独立账号体系，可对接客户 SSO | 可对接 LDAP/企业微信/SSO |
| 日志 | 独立日志空间 | 客户本地日志或指定平台 |

### 数据库

| 项目 | 客户专属实例 | 私有化部署 |
|------|--------------|------------|
| 类型 | PostgreSQL 15+ | PostgreSQL 15+ |
| 部署方式 | Astralink 云上独立实例 | 客户自有数据库或私有云数据库 |
| 隔离方式 | 物理或实例级隔离 | 客户环境完全隔离 |
| 访问方式 | Astralink 运维账号访问 | 按客户安全策略访问 |
| 扩展方式 | 单客户独立扩容 | 客户 IT 负责扩容或协同扩容 |

### 文件存储

| 项目 | 客户专属实例 | 私有化部署 |
|------|--------------|------------|
| 存储介质 | 独立对象存储 bucket | 客户对象存储、NAS 或本地磁盘 |
| 访问控制 | 独立签名 URL 或鉴权代理 | 客户内网访问策略 |
| 文件隔离 | bucket 或目录级隔离 | 完全隔离 |
| 数据迁出 | 可按客户打包迁出 | 客户直接掌控 |

### 备份策略

| 类型 | 客户专属实例 | 私有化部署 |
|------|--------------|------------|
| 数据库备份 | 独立自动备份，保留 14-30 天 | 遵循客户备份制度 |
| 文件备份 | 独立对象存储版本控制 | 客户存储备份机制 |
| 发布前快照 | 每次发布前创建 | 与客户 IT 确认窗口 |
| 恢复演练 | 每半年至少一次 | 按客户合规要求 |
| 数据导出 | 支持全量导出 | 客户本地导出 |

### 适合客户

- 对数据隔离和合规要求较高的机构。
- 有集团、校区或内网访问要求的客户。
- 需要对接内部系统、SSO 或客户自有存储的客户。
- 愿意承担更高部署和维护成本的客户。

### 优点

| 优点 | 说明 |
|------|------|
| 数据隔离强 | 独立数据库和文件存储降低串租户风险 |
| 合规友好 | 更容易满足客户内控和审计要求 |
| 可深度定制 | 可按客户流程扩展专属功能 |
| 故障影响面小 | 单客户实例问题不影响其他客户 |
| 迁出可控 | 数据归属和迁移路径清晰 |

### 缺点

| 缺点 | 说明 |
|------|------|
| 上线周期更长 | 需要环境准备、网络联调和安全审批 |
| 运维成本更高 | 每个客户都需要独立监控和升级 |
| 升级复杂 | 定制化可能导致版本分叉 |
| 资源利用率低 | 单客户独占资源成本更高 |
| 支持依赖客户 IT | 私有化环境问题排查链路更长 |

### 预估维护成本

| 成本项 | 客户专属实例 | 私有化部署 |
|--------|--------------|------------|
| 基础云资源 | 中 | 客户承担或高 |
| 数据库 | 中-高 | 客户承担或高 |
| 文件存储 | 中 | 客户承担 |
| 运维人力 | 中 | 高 |
| 升级成本 | 中 | 高 |
| 客户支持 | 中-高 | 高 |
| 适合收费模式 | 专属实例年费 + 运维费 | 项目交付费 + 年度维护费 |

## 两种方案对比

| 维度 | Astralink 云端托管版 | 客户专属实例 / 私有化部署 |
|------|----------------------|----------------------------|
| 上线速度 | 快 | 中-慢 |
| 初始成本 | 低 | 中-高 |
| 长期维护 | 低-中 | 高 |
| 数据隔离 | 逻辑隔离 | 独立实例或物理隔离 |
| 定制能力 | 中 | 高 |
| 升级效率 | 高 | 中-低 |
| 合规适配 | 中 | 高 |
| 故障影响面 | 可能影响多租户 | 单客户影响 |
| 适合阶段 | 试用、标准 SaaS、快速推广 | 大客户、强合规、深度定制 |

## 推荐策略

### 朗睿教育 V1 推荐

优先推荐“客户专属实例”作为正式版上线方案：

1. 朗睿教育进入真实业务试用后，包含学员、家长、财务和课时数据，独立实例更便于客户信任和验收。
2. 可保留 Astralink 运维能力，减少完全私有化部署带来的交付复杂度。
3. 后续如果客户明确要求内网或自有数据库，再升级为私有化部署。

### 商业化推荐

| 客户类型 | 推荐方案 |
|----------|----------|
| 小型机构、试用客户 | Astralink 云端托管版 |
| 中型机构、重视数据隔离 | 客户专属实例 |
| 集团客户、强合规客户 | 私有化部署 |
| 深度定制客户 | 私有化部署或专属实例 |
